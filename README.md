# Proyecto de Ray Tracing con Diligent Engine

En este proyecto se implementa un sistema de ray tracing utilizando como base el Tutorial 21 del repositorio DiligentSamples. El objetivo principal es renderizar una escena tridimensional aplicando distintos materiales a los objetos, logrando así una simulación realista de la interacción de la luz con las superficies.

## Materiales implementados

Se trabajó con distintos objetos distribuidos en la escena, a los cuales se les asignaron materiales personalizados para observar sus efectos en la iluminación y reflexión. Los materiales aplicados fueron los siguientes:

### Cubos grandes (cubos principales de la escena)
- **Cubo central**
- **Cubo izquierdo**
- **Cubo derecho**

### Esferas pequeñas
Hay múltiples esferas distribuidas aleatoriamente en el plano. A cada una se le asigna uno de los siguientes materiales, en un orden rotativo:
- **Metal pulido**
- **Material base**
- **Material difuso**

### Cubos pequeños
También se incluyeron pequeños cubos distribuidos en el escenario. Estos utilizan materiales de:
- **Vidrio translúcido**
- **Superficie Lambertiana**
